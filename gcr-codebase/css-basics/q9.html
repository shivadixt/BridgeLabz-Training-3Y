FinTwin & WebRTC: Computer Science Student Shiva Dixit Architects Resilient Digital Systems

By Special Tech Correspondent • Featuring Shiva Dixit (G.L.A University)

FinTwin financial digital twin architecture with 5 microservices.

In an era where distributed systems and ultra-low latency determine the efficiency of global industries, software engineering undergraduate Shiva Dixit from G.L.A University, Mathura, is making waves with cutting-edge architectural implementations.

His flagship initiative, FinTwin, represents a state-of-the-art financial digital twin platform. Composed of five autonomous FastAPI microservices—Account, Transaction, Twin Engine, Risk Analysis, and Notification—FinTwin processes complex live simulations without mutating underlying financial ledgers.

"The core objective behind FinTwin is enabling high-velocity financial risk exploration through stateless computation," explains Dixit. By integrating Redis in-memory caching and JWT security, FinTwin maintains sub-millisecond query performance across distributed endpoints.

"Modern distributed systems must marry cloud scalability with real-time peer-to-peer resilience."

Beyond backend microservices, Dixit has pushed the boundaries of real-time web gaming with his Polygon Game project. Built using native HTML5 Canvas and vanilla JavaScript, the game leverages WebRTC peer-to-peer data channels for seamless, multi-user polygon battlefields.

To coordinate peer connectivity across diverse NAT and firewall topographies, Dixit engineered a dedicated Node.js signaling server deployed continuously on Render with custom render.yaml automation and TURN server integration.

Complementing his practical project leadership, Dixit is an AWS Academy Graduate certified in Cloud Foundations. His hands-on proficiency spans Amazon EC2, S3, IAM, AWS Lambda serverless functions, and CloudFormation infrastructure-as-code automation.

With a strong academic foundation (B.Tech CSE, CGPA 7.05) and secondary schooling from Shemford Futuristic K12 School (76%), Dixit continues to explore containerized architectures with Docker Compose, Kafka event streaming, and Kubernetes deployment on AWS EKS.
